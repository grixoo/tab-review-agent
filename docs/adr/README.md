# Architecture Decision Records

ADR-0001 through ADR-0011 record the decisions behind the v1 design in
[architecture design](../architecture/infrastructure-architecture-review-agent-v1.md).

**Lab context.** This is a personal, non-production Azure lab exercise, not a real
corporate build. There is no real Technology Architecture Board and no real Atlassian
org — "TAB", "sign-off", "Deciders: ... Technology Architecture Board" and similar
language in these ADRs describe a role-played enterprise workflow used to make the
exercise realistic. Treat any such decision as self-approved by the lab owner, and use
only synthetic/fictional submissions and data — never real corporate content. The
technical decisions themselves (read-only access, evidence tagging, query sanitisation,
etc.) are still worth enforcing for real, since practicing them properly is the point
of the exercise.
