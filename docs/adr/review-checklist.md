# ADR review checklist

Review the current changes against every numbered ADR in this directory.
For each ADR, report one of:

- CONSISTENT — the change respects the decision.
- CONTRADICTS — quote the decision and identify the conflicting change.
- SUPERSEDES — explain the intended reversal and the new ADR required.

Report findings without automatically changing architecture decisions. Preserve
ADR status and history unless explicitly asked to revise them. This checklist
can be requested in plain language in Codex; no slash command is required.
